# ATM-Java-Application

This is a simple console-based **ATM simulation project** written in Java.

It allows users to perform basic banking operations such as:

###  Features
- Create a new account with password protection
- View account details
- Deposit money (with password validation)
- Withdraw money (with balance check & password)
- Check if an account exists
- Show all account details
- Change account password
- Input validation and error handling

###  Technologies Used
- Java (Core Java)
- Scanner class for input
- OOP Concepts (Classes, Objects, Encapsulation)
- ArrayList for storing accounts

---

###  How to Run

1. Clone or download the repo
2. Open the folder in any Java IDE (like IntelliJ IDEA, Eclipse, or VS Code with Java)
3. Compile and run the `ATM.java` file (which contains the `main` method)
